# আমার বাংলাদেশ

A mobile-first Bangla/English community where Bangladeshis ask questions, answer them and find what others already asked, with a one-minute personality quiz ("Where is your Bangladesh?") as a fun way in.

- **Community (home, `/`):** an interactive map of the 8 divisions, latest / unanswered / solved discussions, topics. Ask (questions, discussions, tips, help requests), answer with simple formatting (bold, lists, links) and up to 4 photos (re-encoded without location or camera data, shown in a grid with a full-screen viewer), reply in threads, mark answers helpful, accept a solution, search, notifications on the site and by email. Reading is open; writing needs a login (Google, Facebook, phone code or email) and can be anonymous. Reports, auto-hide and moderation keep it civil.
- **Quiz (`/quiz`):** 8 questions → one of 9 places, a share card (story or square, 4 designs × 6 colour themes), and friend links (`/r/{code}`) that show how much two friends match.
- **Languages:** Bangla at `/…`, English at `/en/…`. Public pages are cookieless and cacheable.

Architecture, conventions and gotchas for contributors (and for Claude Code) are in `CLAUDE.md`. Plans and work logs live in `docs/`, which is local only (gitignored).

## Setup

```sh
composer install && npm install
cp .env.example .env && php artisan key:generate   # set DB_* (MySQL 8) and APP_URL
php artisan migrate --seed                         # quiz content + super admin (set SUPER_ADMIN_PASSWORD in .env first)
php artisan storage:link                           # public/storage → storage/app/public (member photos)
php artisan db:seed --class=DemoCommunitySeeder    # optional, local only: 40 fictional members, 67 posts, threads, drawn demo photos
npm run build                                      # or `npm run dev` with `php artisan serve`
php artisan quiz:og-images                         # link-preview images (needs google-chrome)
```

Tests run against a MySQL database `amarbangladesh_test` (see `phpunit.xml`): `php8.2 artisan test`. Sign-in methods appear once their keys are set (see `.env.example`).

Useful commands: `community:purge-demo` (remove the demo community), `quiz:simulate` (result balance), `quiz:purge-plays` (wipe test plays), `admin:ensure-super-admin`, `community:send-notification-emails` and `community:prune-photos` (both scheduled). The home map's division shapes are generated by `scripts/build-division-map.py` from geoBoundaries (public domain).

## Admin

`/admin`, grouped by module:

- **Overview · Analytics:** quiz funnel (visitors → started → completed → shared, counted as people, against the previous period), start rate by entry, plays by hour, the quiz → community funnel, share of posts that use formatting, CSV export. Numbers are kept a few minutes per range ("count now" recounts).
- **Community · Moderation:** reported and auto-hidden posts and answers with their photos (keep or remove), blocking members.
- **Quiz · Plays, Questions, Places, Balance:** all plays with filters; answer cards with trait sliders and place bonuses (live balance preview, drag to reorder); text, colour, trait profile and community area per place; how often each place wins across every answer combination (healthy band 6–18%), also for adventurous players, plus a replay of real players' answers.
- **Account · Password.**


## Deploy

Files are in `deploy/`: `nginx.conf`, `env.production.example`, `deploy.sh`, `crontab`; for Laravel Forge see `deploy/FORGE.md`. They're written for an Ubuntu VPS with nginx, PHP 8.2-FPM (Laravel 12; 8.3/8.4 work too), MySQL and Node 18.18+, behind Cloudflare.

**First install**

```sh
git clone git@github.com:rbraju3m/amarbangladesh.git /var/www/amarbangladesh && cd /var/www/amarbangladesh
cp deploy/env.production.example .env        # fill APP_URL, DB_*, SUPER_ADMIN_PASSWORD
composer install --no-dev --optimize-autoloader
php artisan key:generate
npm ci && npm run build
php artisan migrate --force --seed            # seed ONCE: quiz content (migrate also creates the super admin)
php artisan storage:link                      # member photos are served from public/storage
php artisan optimize
sudo chown -R www-data:www-data storage bootstrap/cache
```

Before going live, `php artisan quiz:purge-plays` removes test plays and analytics (content and admins stay). Never run the demo community seeder in production (it refuses to). Then install `deploy/nginx.conf`, and add `deploy/crontab` with `crontab -e` (scheduler + daily DB and photo backup). The scheduler and the web server must be able to delete each other's photo files (same user, or one group: the public disk writes group-writable files).

**Updates:** `deploy/deploy.sh` (maintenance mode → pull → build → migrate → cache → up). Updates don't re-run the seeder, so quiz content changed in code also needs a data migration; content edited in the admin is live immediately.

**Cloudflare**

- SSL/TLS mode **Full (strict)**, with a Cloudflare Origin Certificate on the server. Turn on "Always Use HTTPS".
- Keep `TRUSTED_PROXIES=cloudflare` in `.env`. Without it every visitor shares one rate limit. Check the IP list every few months with `scripts/cloudflare-ips.sh`.
- Cache Rule: *Eligible for cache*, respect origin headers, for public pages (`/`, `/quiz`, `/r/*`, `/feed*`, `/p/*`, `/u/*`, `/search*`, and the same under `/en`) and `/api/feed`. The app sends `s-maxage` and sets no cookies on them; community writes use a header token, never a cookie.
- Cache Rule: *Bypass cache* for `/admin*`, `/auth/*` and the other `/api/*` routes.
- After changing quiz content in the admin, purge `/quiz` in Cloudflare, or wait up to 10 minutes.

**Shared hosting / cPanel (Apache):** point the domain's document root at `public/` (or upload `public/` into `public_html` and fix the paths in `index.php`). Laravel's `public/.htaccess` handles the rewrites. Add the scheduler line as a cPanel cron job. Run `npm run build` locally and upload `public/build/` if there's no Node on the host.

**After going live:** test a result link in Facebook's Sharing Debugger (developers.facebook.com/tools/debug) and point an uptime monitor at `/up`.
